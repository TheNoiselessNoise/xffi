# xffi_gen

Experimental code-generation tools for xffi.

This package contains experimental work toward generating Dart bindings from C header (`.h`) and source (`.c`) files.

## Status

**Private and experimental.** This package is not intended for public use and is not part of the supported xffi runtime API.

The generator is a work in progress. Its output, supported C constructs, and command-line interface may change or be removed without notice.
